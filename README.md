## Github repository for the manuscript titled: "Genetic effects on histone modifications are detectable as DNA methylation QTLs"

### Summary: 
Analysis codes for colocalization of histone acetylation QTLs (haQTLs) and DNA methylation QTLs (mQTLs). 

### Description:
This repository contains R scripts accompanying our study of colocalization between haQTLs and mQTLs using GTEx, ROSMAP, and NIMH datasets. Here, we examine the shared genetic regulation of histone acetylation and DNA methylation within and across tissues. These codes are organized into the following folders: 

#### "01_colocalization": 
##### Primary Bayesian colocalization analyses using coloc.abf() for GTEx skeletal muscle haQTLs and mQTLs, ROSMAP DLPFC haQTLs and array-based mQTLs, and ROSMAP DLPFC haQTLs and NIMH WGBS-based mQTLs. 
#### "02_NIMH_WGBS_mQTL_pvalue_impuation": 
##### Summary statistics imputation for NIMH whole-genome bisulfite sequencing (WGBS) mQTLs using SSimp. 
#### "03_Figures": 
##### R scripts for generating selected main-text figure panels (Figures 2–5).
