# haQTL-colocalization
Analysis codes for colocalization of histone acetylation and QTLs. 
This repository contains R scripts accompanying our study of colocalization between histone acetylation quantitative trait loci (haQTLs) and DNA methylation quantitative trait loci (mQTLs) using GTEx, ROSMAP, and NIMH datasets. The analyses investigate shared genetic regulation of histone acetylation and DNA methylation within and across tissues.
folder "01_colocalization": Primary Bayesian colocalization analyses using coloc.abf() for GTEx skeletal muscle haQTLs and mQTLs, ROSMAP DLPFC haQTLs and array-based mQTLs, and ROSMAP DLPFC haQTLs and NIMH WGBS-based mQTLs.
folder "02_NIMH_WGBS_mQTL_pvalue_impuation": Summary statistics imputation for NIMH whole-genome bisulfite sequencing (WGBS) mQTLs using SSimp.
folder "03_Figures": 	R scripts for generating selected main-text figure panels (Figures 2–5).
